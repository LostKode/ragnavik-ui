# Ragnavik UI

Ragnavik UI brings the Ragnavik experience into Valheim with a branded main menu, community links, Ragnavik updates, custom loading screens, helpful gameplay tips, and a dedicated character selection experience.

## Main menu

The main menu includes the Fjord Gate mark and quick links to Ragnavik community support. A separate Ragnavik Updates panel keeps server and pack news easy to find without replacing Valheim's own news.

## Ragnavik characters

Ragnavik uses a dedicated character list so your Ragnavik adventurers stay separate from characters used in other worlds. Existing Valheim characters are left untouched and are not shown in the Ragnavik selector.

If you are joining Ragnavik for the first time, create a new character from the character selection screen. Your character still benefits from Valheim's normal save, backup, cloud, and recovery features.

## Loading screens

Original Ragnavik artwork and randomized tips appear while the game starts and while you enter a world or server. Portal travel continues to use its normal loading experience.

## Installation

Ragnavik UI is included with the Ragnavik Client Pack and requires no separate setup or configuration.
