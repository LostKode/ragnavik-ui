# Ragnavik UI

Client UI fixes for the Ragnavik Valheim pack. AzuClock's full clock, day, time of day, and weather display sits closer below HUDCompass. The included Ragnavik UI BepInEx plugin places armor, gold, weight, and trash in four aligned rows along the right side of the inventory. It keeps the trash click area aligned with the visible button, preserves drag-to-delete behavior, and fits the controls within smaller inventory views.

Install this package through Ragnavik 1.1.12 or newer. Its plugin is client only. Ragnavik Server 1.0.6 or newer allows the plugin ID `lostkode.ragnavik.ui` in the anti-cheat profile; the dedicated server does not need this UI plugin.
